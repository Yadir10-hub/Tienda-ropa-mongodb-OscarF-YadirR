

# Tienda de Ropa MongoDB OyY

## Descripción

Proyecto académico desarrollado utilizando MongoDB para administrar una tienda de ropa.

La base de datos permitirá gestionar información sobre:

* Usuarios
* Marcas
* Prendas
* Ventas
